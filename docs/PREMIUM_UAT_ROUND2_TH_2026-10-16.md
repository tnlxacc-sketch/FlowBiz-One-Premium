## เกณฑ์ที่ยังไม่ยืนยัน

| ขอบเขตที่ต้องผ่านก่อนรับรองครบ | สถานะ |
|---|---|
| Login จริงแยก 6 Role และกดทุกปุ่มทุกเมนู | ยังทดสอบไม่ได้: ไม่มี control-browser ที่ Sites รองรับ |
| Upload/View/Download POD ผ่าน Storage และหน้าจอ | ยังไม่ผ่านการยืนยัน |
| รับสินค้าบางส่วน คืนสินค้า และค่าใช้จ่ายเพิ่มเติมครบวงจร | ยังไม่ผ่านการยืนยัน |
| ผู้ใช้หลายคนกดจอง/อนุมัติ/จ่าย Stock พร้อมกัน | ยังไม่ผ่านการยืนยัน |
| ตรวจสิทธิ์ SECURITY DEFINER รายฟังก์ชันครบ 58 รายการที่ Advisor เตือน | ยังไม่ครบ |
| ตรวจเวลาตอบสนองจริง Mobile/iPad และหน้าจอทุกขนาด | ยังไม่ผ่านการยืนยัน |

ตรวจหาปลั๊กอิน browser automation เพิ่มเติมแล้ว ผลที่คืนไม่พบตัวที่เหมาะกับงาน จึงไม่เสนอให้ติดตั้งปลั๊กอินอื่นที่ไม่เกี่ยวข้อง
ไม่ใช้การตรวจโค้ด การ render จำลอง หรือ SQL แทนหลักฐานการคลิกจริง
